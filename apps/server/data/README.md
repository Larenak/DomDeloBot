# Открытые сведения о домах

## Управляющие организации

Каталог в папке uk построен из [набора «Износ и аварийность многоквартирных домов»](https://tochno.st/datasets/gisgkh) проекта «Если быть точным». Первичный источник сведений — открытая часть ГИС ЖКХ. Снимок от 17.09.2026, обработка «Если быть точным», лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Сохранены только код ФИАС, регион, способ управления, название организации и ссылка на её карточку в ГИС ЖКХ.

Для обновления: проверить текущую ссылку CSV на странице набора, изменить URL в tools/build-uk-index.mjs, запустить из корня проекта node tools/build-uk-index.mjs, обновить дату снимка в public-housing-data.ts и проверить сопоставление нескольких домов. Исходный CSV весит около 584 МБ; скрипт читает его потоком, без записи сырой выгрузки на диск.

## Капитальный ремонт

Сервер запрашивает открытые региональные выгрузки [витрины ФРТ](https://xn--80adsazqn.xn--p1aee.xn--p1ai/opendata): КР 1.1 (дом и фонд) и КР 1.3 (работы). Поиск дома — по коду ФИАС; связывание работ — по коду МКД и ОКТМО внутри одного региона. В интерфейсе показываются дата выгрузки и ссылки на конкретные файлы. Изменение структуры страниц или CSV ФРТ потребует обновления парсера.
